# BPA Website Design Team — Starter Foundation

This is a **student-editable, static website foundation** for BPA event 955, Website Design Team.

## What is included
- `index.html`: landing page
- `heroes.html`: Hero Spotlight page
- `impact.html`: Community Impact page
- `get-involved.html`: Get Involved page, with a demo-only nomination form
- `css/styles.css`: design tokens, responsive layout, reusable styles
- `js/main.js`: mobile navigation, dynamic footer year, demo form behavior
- `assets/`: location for team-created images, video, icons, and other media
- `documentation/`: brand, research, citation, AI-use, and QA templates

The three subpages are selected from the event's allowed page types. The team can replace or add pages, for example Why They Matter, Photo Gallery, Interview/Q&A, Resources & Links, or a full Nomination Page.

## Important design choice
This starter uses **plain HTML, CSS, and JavaScript with no external libraries or network dependencies**. That makes the initial version easy to open locally and test without internet access. Students can still use Replit as their editor. If the team later decides to add Bootstrap, download and include the Bootstrap files locally rather than relying on a CDN for the competition build.

## Open the project
1. Extract the ZIP.
2. Open the folder in Replit or Visual Studio Code.
3. Open `index.html` in a browser to preview it. For local development, a simple static server or Replit preview is also fine.
4. Edit the CSS variables at the top of `css/styles.css` to establish the team's final visual identity.
5. Replace all bracketed placeholders and sample text with verified team research and original content.

## Before presenting or submitting
- Replace the illustrative "Everyday Impact" name, EI mark, colors, and typography if the team chooses a different brand.
- Replace every placeholder with researched, verified content.
- Obtain permission/release forms for identifiable people and their images or work, as applicable.
- Credit all third-party assets and research on the Works Cited page.
- Complete BPA AI usage documentation accurately. The event document identifies AI Policy Level 2 as permitted; verify the current official policy and forms before submission.
- Test every link, form behavior, image, and page at desktop and mobile widths.
- Test the exported folder offline on a different computer/browser.
- Keep a record of each student's contributions and ensure every team member can explain the implementation.

## Suggested student workflow
1. Research and interview; record sources and permissions.
2. Agree on brand direction and edit `documentation/brand-guidelines.md`.
3. Sketch each page before coding.
4. Build page content and components; use CSS variables for consistency.
5. Add original media and lightweight interactions.
6. Run the QA checklist and rehearse the presentation.

## No backend
The nomination form is deliberately a local demonstration. It does not transmit, store, or email submissions. Do not imply that it is a functioning public submission form.
