## 3. Color palette
Starter palette (change after team approval):
- Deep teal: `#173B3A` — primary headings / navigation
- Warm gold: `#E7A45B` — accent
- Ivory: `#F5F0E7` — page backgrounds
- Terracotta: `#B65F48` — secondary accent
- Charcoal: `#263638` — body text

Document final choices and the role of each color. Check text contrast for accessibility.

## 4. Typography
Starter uses Georgia for display headings and Arial for body text. Select no more than two font families unless there is a clear design reason. If using downloaded fonts, include local font files and verify their license and offline behavior.

## 5. Photography and illustration
- Prefer original photographs, interviews, illustrations, and infographics.
- Obtain permission before publishing identifiable people.
- Keep an asset log with creator, source, license/permission, and date accessed.
- Use consistent cropping, lighting, and image treatment.
- Never invent a person's story or present an AI-generated image as a real person.

## 6. Components
Define consistent rules for:
- Header and navigation
- Footer
- Buttons and links
- Profile / hero cards
- Quote blocks
- Statistics and data visualizations
- Forms and notices
- Image galleries

## 7. Motion and interaction
Use motion only when it improves comprehension:
- Short, subtle hover feedback
- Optional small entrance transitions
- No essential information conveyed only through animation
- Avoid autoplay audio/video and excessive parallax
- Respect reduced-motion settings

## 8. Voice and writing
Describe the tone (e.g., respectful, specific, optimistic, evidence-based). Use plain language. Attribute quotes and verify factual claims.
