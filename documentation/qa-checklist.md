# BPA Website QA Checklist

Use this checklist throughout development and again before submission.

## Event requirements
- [ ] Website celebrates unsung heroes in the local community.
- [ ] Landing page is present.
- [ ] At least three eligible subpages are present.
- [ ] Website is original and has not been submitted previously to BPA.
- [ ] Team members can explain their individual roles and the overall site.
- [ ] Required submission materials are prepared as specified in the current event guidelines.

## Content and copyright
- [ ] Names, roles, quotations, and claims are verified.
- [ ] Works Cited covers research and all third-party assets.
- [ ] Image / work release forms are obtained where required.
- [ ] All media licenses and permissions are checked.
- [ ] AI usage is documented in accordance with current BPA policy.
- [ ] No placeholder text or fabricated statistics remain.

## Design and usability
- [ ] Visual identity is consistent across pages.
- [ ] Navigation is obvious and consistent.
- [ ] Text hierarchy is clear and readable.
- [ ] Color contrast is sufficient.
- [ ] Images have useful alternative text.
- [ ] Layout works on phone, tablet, and desktop widths.
- [ ] Keyboard focus is visible and links/buttons are usable by keyboard.
- [ ] Reduced-motion preference is respected.

## Technical
- [ ] All navigation links work.
- [ ] No broken images, missing files, or console errors.
- [ ] Forms clearly explain what happens to submitted information.
- [ ] No external network dependency is required for the offline presentation.
- [ ] Website tested in at least two browsers.
- [ ] Website tested offline on a second device.
- [ ] Local assets are organized and filenames are clear.

## Presentation
- [ ] Setup can be completed within 3 minutes.
- [ ] Presentation is rehearsed to fit within 5 minutes.
- [ ] Each team member can explain their contribution.
- [ ] Team can answer questions about layout, navigation, graphics, media, coding, compatibility, and content.
